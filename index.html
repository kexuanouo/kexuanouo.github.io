07 / ESP

七個開關
七件不同的事

ESP 分頁上只有七個開關，沒有一個是多餘的。每一個都在回答一個具體問題：他在哪、剩幾血、有沒有見聞色、吃了什麼果實。

下面每個數字都是從原始碼讀出來的，不是估的。

01

06

Ken ESP見聞色

讀對手的 KenActive、KenDodgesLeft、KenMaxDodges 三個屬性，直接寫成 Ken: Active [3/5]——他還剩幾次閃避，一眼看完。

跟 Name ESP 共用同一個 billboard，不各畫一個：只開 Ken 是 160×15，只開 Name 是 160×30，兩個都開變 160×50。關掉一個不會把另一個也拆掉。

狀態色 綠 ACTIVE · 紅 INACTIVE · 灰 NONE
07

Fruit ESP

對手吃了什麼果實，粉色標籤插進名字行。要先開 Name ESP——它不是獨立繪製的。讀取包在 pcall 裡，遊戲改 Data 結構也不會炸。

-- 雙重距離：3D 或水平投影，任一命中就出手
local dist  = (hrp.Position - myPos).Magnitude
local d2    = Vector2.new(hrp.Position.X, hrp.Position.Z)
              - Vector2.new(myPos.X, myPos.Z)

if dist <= range or d2.Magnitude <= range then
  for _, part in ipairs(mob:GetChildren()) do
    if part:IsA("BasePart") then
      targets[#targets + 1] = {mob, part}
    end
  end
end

-- 六路流轉：每次發包換一條序列
local function FireAttack(targetList)
  if #targetList == 0 then return end
  local headPart = targetList[1][1]:FindFirstChild("Head")
  if not headPart then return end

  pcall(function()
    RegisterAttack:FireServer()

    if State.CurrentLogic == 4 then
      RegisterHit:FireServer(headPart, targetList, {})
      task.delay(0.001, function()
        RegisterHit:FireServer(headPart, targetList, {})
      end)
    else
      RegisterHit:FireServer(headPart, targetList, {})
    end
  end)

  -- 下一發走另一條路
  State.CurrentLogic = (State.CurrentLogic % 6) + 1
end
